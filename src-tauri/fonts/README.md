# Fonts

Montserrat (Julieta Ulanovsky and contributors) from Google Fonts, licensed under the SIL Open Font License 1.1: https://openfontlicense.org

Static TTF instances with Latin and Latin Extended glyphs. Their name tables were changed so every weight uses the family name `Montserrat`, because libass looks fonts up by family name and Google ships these files as "Montserrat Thin". The app bundles them so burned-in subtitles look the same as the preview.
